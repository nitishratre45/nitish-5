# NITISH 5

An original mobile-first 3D open-world action-driving game prototype built with Godot 4.

## Current prototype
- Procedurally generated low-poly city blocks
- Third-person character movement and follow camera
- Starter car with enter/exit interaction
- Collectible mission checkpoints
- Touchscreen controls and keyboard controls
- Android debug APK GitHub Actions workflow

## Run locally
1. Install Godot 4.3 or newer.
2. Import `project.godot`.
3. Press Play.

## Controls
- WASD / arrows: move
- Space: jump
- E: enter/exit car near the vehicle
- On-screen buttons: mobile movement and actions

## Android
Push to `main` or manually dispatch the Android APK workflow. The build is a debug APK; a signed release requires your own signing keystore and GitHub secrets.
